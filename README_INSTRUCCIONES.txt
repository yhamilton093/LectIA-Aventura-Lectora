LECTIA PWA — INSTALACIÓN

1. Descomprime el ZIP.
2. Entra a https://app.netlify.com/drop y arrastra la carpeta LectIA_PWA (o su contenido).
3. Abre el enlace HTTPS que genera Netlify en Chrome.
4. En Android: menú ⋮ > Añadir a pantalla principal > Instalar aplicación (si está disponible).
5. En PDI: abre la misma URL en Chrome. Si Chrome ofrece instalar, usa el icono de instalación; si no, crea un acceso directo.
6. Abre una vez con internet para guardar los archivos para uso sin conexión. La voz puede depender de voces del dispositivo y no funcionar sin conexión.

AVISO: esta app guarda datos solo en el navegador local. No uses nombres reales de menores. Exporta respaldos regularmente. No hay cuentas ni sincronización entre dispositivos.
